# Support

For help installing, signing in to, or using Adspirer Social Ads:

- Email: [support@adspirer.com](mailto:support@adspirer.com)
- Documentation and troubleshooting: [adspirer.com/docs](https://www.adspirer.com/docs)
- Bugs and feature requests: [GitHub issues](https://github.com/Adspirer/adspirer-social-ads-antigravity-plugin/issues)

When you write in, include what you asked, what happened, and the ad platform involved. Remove
account ids, tokens and customer data first. Report security problems privately; see
[SECURITY.md](SECURITY.md).
